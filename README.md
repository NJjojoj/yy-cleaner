# YY清理工具

轻量清理工具，专清 YY 语音在 `%APPDATA%\YY` 和 `%LOCALAPPDATA%\YY` 下产生的缓存、日志、崩溃转储与更新包。

## 组成

| 文件 | 作用 |
|---|---|
| `YY清理工具.ps1` | 主脚本，WinForms 外壳 + 清理逻辑 |
| `YY清理工具.exe` | 由脚本封装的单文件程序（双击即用，会自提权） |
| `打开YY清理工具.cmd` | 无 exe 时的入口 |
| `图标.ico` | 程序图标 |
| `操作日志.txt` | 历史清理记录 |

## 清理范围

- 缓存、图片缓存、语音缓存
- 日志与崩溃转储
- 更新安装包残留

不动账号配置、聊天记录、安装目录内的程序文件。

## 注意

- 需要管理员权限
- YY 运行时缓存文件被占用，删掉的空间要关掉 YY 后才真正归还
